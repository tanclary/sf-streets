# sf streets // 415

Progressive Web App to track walking every street and block in San Francisco (**14,203 official DataSF blocks** across **1,930 named streets** and **42 neighborhoods**).

## Features
- **Zero-backend PWA**: Installable directly to iOS / Android home screen (`Add to Home Screen`).
- **Strava Sync**: Connect via Strava v3 API (OAuth or personal Access Token) to snap all your `Walk`, `Run`, and `Hike` polylines against SF blocks.
- **Garmin & GPX / TCX / JSON Drop**: Drag and drop `.gpx`, `.tcx`, or Strava activity `.json` files.
- **Live Phone GPS Walk Recorder**: Record walks directly in the browser and watch blocks complete in real time.
